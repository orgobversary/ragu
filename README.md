# ragu

---

  Build a reliable, auditable customer-support agent that calls tools, hands off requests to specialist agents, and protects itself with input guardrails.

1. Implement robust tools for orders, complaints, payment methods, and FAQs with strict validation and helpful errors.


2. Develop an agent that interacts with tools effectively by gathering required information, making one request at a time, and providing concise responses.


3. Compose agents via agent-as-tool to delegate FAQ-style questions to a specialized knowledge assistant.


4. Route with triage handoffs to answer simple questions centrally and hand off orders/complaints to specialist agents.


5. Enforce input guardrails to block unsafe or off-topic inputs with a security-and-topic tripwire.


6. Explore advanced options: leverage File Search (RAG), optimize reasoning effort, and add basic session memory.
